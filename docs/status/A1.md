# A1 — gameplay status

## State: PR OPEN (`feat/gameplay` → `main`)

Base `47d365b`. Only `src/game/`, `src/state/` (unchanged), `tests/unit/gameplay.test.ts` and this file were touched. No contract, dependency or A0-file change was needed.

## What changed

- **Movement** (`src/game/movement.ts`, `Player.tsx`): exponential accel/decel (`ACCEL_RATE 14`, `DECEL_RATE 18`), shortest-arc heading ease, speed-driven walk phase (bob/squash). Frame dt is clamped to 50 ms; `playerTransform` is written in the frame loop, the store only every ~100 ms. Axes are camera-relative for the fixed elevated camera (W = -Z north, D = +X east). `KeyZ`/`KeyQ` accepted for AZERTY.
- **Collision** (`collision.ts`): circle-vs-AABB against `CityDefinition.blockers` with sliding, bounds inset by `PLAYER_RADIUS`, substeps of ≤ radius/2 so thin walls cannot be tunnelled, and depenetration if a spawn/socket overlaps a blocker. `absorbBlockedVelocity` kills the blocked component so there is no wall jitter.
- **Pickup feedback** (`Collectibles.tsx`, `feedback.ts`): glint pulses/scales/brightens with proximity, ground ring, one-shot burst (expanding ring + spark) on collection via a mutable pulse channel — no per-frame React state. Store remains the sole collection validator; the Player syncs position, flushes the clock, dispatches `COLLECT`, and only marks the burst if the store accepted it.
- **Clock** (`clock.ts`): reusable `ClockAccumulator` emitting ~100 ms `TICK`s, flush on blur/hidden, rebase on focus/visible so hidden-tab gaps are never charged. `flushRunClock()` scores the last partial chunk before the final pickup freezes the result. Travel-phase PAUSE behaviour (`isRunPhase`) is untouched and still covered by `store.test.ts`.
- **Touch** (`input.tsx`): `setTouchAxis(x, z)` clamps to [-1, 1], applies a 0.12 dead zone with magnitude rescale, normalises diagonals; `clearTouchAxis()` plus clears on pointercancel/touchcancel, blur, hidden, pause, travel and retry.

## Known issues

- Camera is fixed-offset, so "camera-relative" equals world-axis mapping; if A2/A0 add camera yaw, `Player.tsx` needs the yaw fed in (one `Math.atan2` rotation of the axis).
- The pickup burst is geometry-only; no audio hook yet (A5 owns sound toggles — `pickupPulse.at` is the signal to key off).
- Glint proximity scaling uses `playerTransform` directly; fine for one player, not for a replay view.
