### Collectible cards (`src/game/Collectibles.tsx`, `src/game/targetTextures.ts`)

- Each uncollected objective is a **framed picture card** on its existing socket: ink outline box (3 wu) → cream mat → picture plane (front and back), shallow depth 0.2 wu, ink stand block, hard elliptical ground shadow. Position comes straight from `objective.position`; nothing is nudged.
- Cards **yaw-billboard** toward the camera and **lean back 0.8 rad** so they face the elevated city camera (`CITY_CAMERA_OFFSET` ≈ 55° elevation); gentle bob, tiny roll wobble, mild scale-up and faster orbiting sparks as the explorer approaches (`NEAR_DISTANCE` 9, unchanged). Two small yellow octahedron sparks per card — no beams, rings or global markers.
- Textures: `getTargetTexture(id)` rasterises the registry SVG into one shared 512² `CanvasTexture` per `TargetId` (sRGB, mipmapped, anisotropy 4, cached for the session). Until the image decodes — or if it fails — the canvas holds an **item-specific fallback card** (palette + glyph + first words of the alt text), so a missing texture still identifies the target. `isTargetTextureLoaded(id)` exposes the state for inspection.
- Geometry and non-picture materials are module-level singletons; one `MeshBasicMaterial` per card for the picture (disposed on unmount). Depth test/write are default, so cards occlude correctly behind buildings; only the shadow disables depth write.
- All motion is on refs in `useFrame`; React state changes only when the collected set changes (existing burst lifecycle kept intact).

## Pass 1 — movement / collision / clock / touch (merged in PR #3)

- **Movement** (`src/game/movement.ts`, `Player.tsx`): exponential accel/decel (`ACCEL_RATE 14`, `DECEL_RATE 18`), shortest-arc heading ease, speed-driven walk phase (bob/squash). Frame dt is clamped to 50 ms; `playerTransform` is written in the frame loop, the store only every ~100 ms. Axes are camera-relative for the fixed elevated camera (W = -Z north, D = +X east). `KeyZ`/`KeyQ` accepted for AZERTY.
- **Collision** (`collision.ts`): circle-vs-AABB against `CityDefinition.blockers` with sliding, bounds inset by `PLAYER_RADIUS`, substeps of ≤ radius/2 so thin walls cannot be tunnelled, and depenetration if a spawn/socket overlaps a blocker. `absorbBlockedVelocity` kills the blocked component so there is no wall jitter.
- **Pickup feedback** (`Collectibles.tsx`, `feedback.ts`): one-shot burst (expanding ring + spark) on collection via a mutable pulse channel — no per-frame React state. Store remains the sole collection validator.
- **Clock** (`clock.ts`): `ClockAccumulator` emitting ~100 ms `TICK`s, flush on blur/hidden, rebase on focus/visible; `flushRunClock()` scores the last partial chunk before the final pickup. Travel-phase PAUSE is covered by `store.test.ts`.
- **Touch** (`input.tsx`): `setTouchAxis(x, z)` clamps, 0.12 dead zone, diagonal normalisation; `clearTouchAxis()` on pointercancel/touchcancel, blur, hidden, pause, travel and retry. A5 should call `clearTouchAxis()` on stick release.
