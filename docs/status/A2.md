# A2 — Globe & travel status

Branch: `feat/globe-travel` (off `main` @ `47d365b`). Files touched: `src/world/**` and this doc only.

## Implemented

### `GlobeScene({ cities, onSelectCity, interactive })` — `src/world/GlobeScene.tsx`
- Cartoon Earth: `MeshToonMaterial` over a locally generated `CanvasTexture` (`earthTextures.ts`: original simplified
  ellipse continents, seeded decorative islands, ice caps, sand belt). No remote imagery, no map data.
- Transparent cloud shell (own seeded texture, slow counter-drift), camera-facing radial glow plane, seeded star field
  (`hashSeed('glint','globe-stars')`).
- City markers: reusable cone/sphere/ring geometries and materials at module level; one colour material per accent
  (cached). Labels are Drei `Html` `<button>`s: `data-testid="globe-pin-<id>"`, `aria-label="Travel to <label>"`,
  hover + `:focus-visible` states, Enter/Space activate, `tabIndex=-1` when hidden or non-interactive.
- Far-hemisphere markers are culled (`markerFacing`) and cannot be selected; the hidden set is a ref and React state is
  only set when it changes. Idle rotation (~4°/s, slows on hover/focus), settles back to the idle tilt.
- Travel choreography via `travelSignal` (mutable frame bridge, no per-frame React state): globe turns the destination
  toward the camera and dives (scale up) on entry, pulls back on exit; markers shrink away while travelling.

### `TravelDirector({ travel, destinationReady, paused, reducedMotion, onCovered, onComplete, onFailure })`
- Pure timeline in `travelTimeline.ts` (unit tested): enter 950/180/620 ms, exit 480/80/520 ms, reduced-motion
  0/40/120 ms (effectively an instant cut), timeout 8 s.
- `onCovered` fires once at full cover; hold lasts until `destinationReady && hold elapsed`; `onComplete` after reveal;
  `onFailure(runId, id, TRAVEL_FAILURE_MESSAGE)` if still covered at 8 s. `paused` freezes accumulated time.
- Stale-safety: each transition owns a `TimelineState`; callbacks check `timeline.current === state && !finished`, so a
  replaced/cleared `travel` never fires. Callback identity changes do not restart the timeline (latest-props ref).
- Full-screen DOM cloud overlay (`data-testid="travel-cover"`), `pointer-events-none`, opacity written directly to the
  element (no React state per frame). No store or camera access.

## Five-city arcade globe pass (feat/globe-arcade, base `main` @ d685b09)

Scope approved by owner decision D14: Paris, Giza, Rome, San Francisco, Berlin + cartoon-arcade polish.

Changes (`src/world/` only):
- `earthTextures.ts`: continents are now hand-authored lat/lon polygon silhouettes (N/S America, Africa, Eurasia,
  Australia, Greenland, Antarctica, UK, Japan, Madagascar, NZ) traced with smoothed quadratic curves instead of
  ellipse blobs. Layers: deep→rich blue ocean gradient, seeded shimmer + island specks, shallow-water rim, sandy coast
  stroke, 3 px ink outline, dark/green/mint land fills, desert patches (Sahara, Arabia, Gobi, Outback, US south-west,
  Atacama), polar caps, ~14 large soft baked cloud banks (down from 110 small ones). Still one cached
  `CanvasTexture` (1024×512, painted once at load), same low-quality path.
- `GlobeScene.tsx`: earth/pin materials are `toneMapped: false` so the palette isn't washed out by the renderer's
  ACES pass. Pins have a chunky ink outline (back-face sphere), cream stem, palette focus ring. Labels are arcade style
  (cream/yellow, 3 px ink border, hard bottom shadow, hover/focus lift, 44 px min hit target, 120 ms transitions).
  Pin frames use an east/north/outward basis so `labelOffsets()` can fan clustered European labels away from their
  centroid; a per-frame screen-space check collapses any remaining overlapping label (hidden + `aria-hidden`,
  active pin always wins). Back-facing pins stay hidden and untabbable. State is only set when the hidden/collapsed
  sets actually change (no per-frame React state).
- Travel director, timeline, signal, focus/zoom choreography and reduced-motion path are untouched.
