# A9 — San Francisco status

Owner paths: `src/cities/san-francisco/`, `docs/status/A9.md`, `docs/status/a9-shots/`.

## Implemented
- Golden Gate hero: south tower on the `bridge-approach` blocker, deck + north tower over bay water
  north of the playable bounds (z < -72), sagging main cables with hangers, toll kiosks, cypresses.
- Cable-car street: rails and overhead trolley wires along the main N-S road, brick car barn with
  arched doorway, smokestack and a parked cable car in its forecourt (inside the blocker).
- Three pastel bay-window Victorian rows, wharf sheds with pitched roofs, stepped hill terrace
  (visual only, inside its blocker), harbour inlet + plank pier with sailboats.
- Painted red/white kerbs, dashed lane lines, street trees and lamps, lavender drop shadows.
- Bay water north/east of bounds, stepped background hills west/south with pastel houses, haze band.
- Low quality path drops windows, hangers, wires, kerb paint, most props and hill houses.

## Verified
`npm run typecheck`, `npm test`, `npm run build`; screenshots from `npm run preview` via
`docs/status/a9-shots/shoot.mjs`.

## Known issues
- The chase camera looks steeply down, so the far (north) bridge tower is only visible near the
  bridge district; towers read mostly as bases from street level.
- No real fog (scene fog is A0's SceneHost); haze is a flat horizon band.
- Definition (sockets, districts, blockers) unchanged.
