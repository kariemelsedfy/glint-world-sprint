# A5 — UI status

## State: PR OPEN (`feat/ui` → `main`)

Rebased on `3566c59`. Only `src/ui/**`, this file and `docs/status/a5-shots/` were touched. No contract, dependency or A0-file change was needed.

## What changed

`src/ui/GameUI.tsx` is now the production overlay, adapted from `ai-studio-export/src/ui/` (icons, passport stamps, screens) onto the `UIModel`/`UIActions` contract in `@/shared/contracts`. `MiniWorldCanvas` was not brought across; the only Canvas/camera stay in `src/app`.

- **Overlay discipline** — root is `pointer-events-none`; only controls, cards and modal surfaces opt into `pointer-events-auto`, so the 3D scene stays clickable.
- **Menu** (`MenuScreen`) — `GLINT World Sprint` wordmark, trial buttons named exactly by level title (`Icons`, `Sky & Sun`, `Small Wonders`) → `onSelectLevel`, `SettingsBar` (audio / reduced motion / quality → `onSettings`).
- **Briefing** (`BriefingScreen`) — clue cards from `model.cards`, controls summary, `Go` (accessible name exactly `Go`) → `onGo`, back → `onMenu`. Compact header Go on short landscape.
- **Globe HUD** (`GlobeHUD`) — collapsible clue list, `Clock`, `Pause`, `Fly to Paris` / `Fly to Giza` → `onSelectCity`.
- **City HUD** (`CityHUD` + `ObjectiveCard`) — both objectives as `<li>` passport cards (struck through once collected); the active card shows the clue, the three-tier price ladder (`+10s / +20s / +35s` from `HINT_COST_MS`), purchased hint texts and one purchase button labelled with `card.nextHintLabel` (`Hint 1: city (+10s)` …) → `onHint`. Footer: `Globe`, `Map`, movement copy (`WASD or arrow keys…` on desktop, stick copy on touch).
- **Hint debounce** — the purchase button disables for 700 ms after a press, so a double-click buys one tier (A7 QA item 1). Purchase rules stay in the store; the UI only reports the press.
- **Clock** (`Clock`) — `<strong>m:ss.t</strong>`, `penalty m:ss.t`, `practice` flag; shared by both HUDs.
- **Map** (`MapOverlay`) — SVG in city coordinates (`viewBox` = city bounds, north up): roads, blockers, landmarks, amber search circles, player. Landmark text renders only when `label !== null`. `role="img"` named `${city} map`, `Close` button, Escape closes.
- **Pause** (`PauseModal`) — `Paused`, settings, `Resume` / `Retry` / `Menu`; two-column layout on short landscape.
- **Travel / boot / error** — `TravelOverlay` (`Travelling…`), boot splash, `ErrorOverlay` recovery actions. The WebGL fallback heading comes from `src/app/ErrorBoundary`.
- **Results** (`ResultsScreen`) — medal badge, `Adjusted m:ss.t`, `Active … · hints … · travel …`, points, best-on-device / session-only / practice state, `Retry` → `onRetry`, `Next trial` → `onNextTrial`, `Menu`.
- **Touch** (`TouchControls`) — landscape thumbstick on coarse-pointer devices (or `showTouchControls`), ≥44 px, normalised axes → `onTouchAxis(x, z)`, `(0, 0)` on release/cancel. Knob position is written to the DOM via a ref; no React state per drag frame. Centred under the HUD on short phones.
- **Orientation / motion** — `OrientationNotice` suggests landscape in portrait; `glint.css` honours `prefers-reduced-motion` and `model.settings.reducedMotion` (`.glint-reduced-motion`).

Deterministic content only; no `Math.random()`, no `any`/`@ts-ignore`, no per-frame `setState`.

## Known issues

- Hint purchases happen straight from the objective card (no confirm dialog); the 700 ms disable is the double-press guard.
- The map is a plain rectangle projection; on very wide/tall city bounds the aspect box letterboxes.
- Audio toggle is UI-only until a sound layer exists.
