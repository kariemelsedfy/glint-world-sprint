## What changed in this pass

- **Tokens** — `src/ui/glint.css` defines the approved palette as CSS custom properties on `.glint-ui` (`--ar-ink #211333`, `--ar-lavender #B6A1E8`, `--ar-purple #7146C5`, `--ar-cream #FFF5E9`, `--ar-cyan #22C4EA`, `--ar-pink #F43FAB`, `--ar-yellow #FFD963`) plus `--ar-line 3px`, `--ar-shadow 6px`, small radii and `--ar-fast 120ms`. Chunky 3 px ink outlines, hard offset bottom shadows, highlighted top faces, hover lift, pressed state, `:focus-visible` cyan ring, striped disabled state, ≥44 px controls, safe-area padding, reduced-motion and short-landscape (`max-height: 460px`) rules.
- **Primitives** — `src/ui/components/Arcade.tsx`: `ArcadeButton` (tones yellow/pink/cyan/purple/cream/ink, sizes sm/md/lg, block), `ArcadePanel`, `StatChip`, `PhotoCard` (caller-supplied `src`/`alt` only, optional collected/selected), `Keycap`.
- **Font** — `src/ui/fonts/Anton-Regular.ttf` (SIL OFL 1.1, licence in `src/ui/fonts/OFL-Anton.txt`) bundled via `@font-face`; body uses the system sans stack. No runtime font CDN.
- **Menu** (`MenuScreen`) — globe stays the hero (centre ~60 % clear). Top-left wordmark + exact tagline "See the clue. Find the place. Beat the clock."; top-right audio/settings; six travel-ticket cards along the bottom with abstract city-agnostic SVG art (`TicketArt`), title, difficulty · duration · object count (`trialMeta.ts`, UI-only metadata) and best/medal — "First expedition" when empty. Cards select on **click only** (`onSelectLevel`); hover never touches the store. Copy "destinations stay secret"; no city is named before identification.
- **Briefing** (`BriefingScreen`) — one `PhotoCard` per target from `card.imageUrl`/`imageAlt`, clue, "City unknown"; controls strip; yellow `Start hunt` (accessible name still `Go`).
- **City HUD** (`CityHUD`, `ObjectiveCard`) — top-left compact timer chip + `Found n/m` + city; top-right the selected target's photo, clue, tier ladder (`+10s / +20s / +35s` from `HINT_COST_MS`, bought tiers marked) and one pink purchase button labelled with `card.nextHintLabel` (real next cost) → `onHint`, 700 ms post-press disable. Other targets are small photo tabs (`ObjectiveTab`). `GLOBE` bottom-left, `MAP` bottom-right, `Pause` top-right. Only working keycaps (W/A/S/D) are labelled. On collection the thumbnail animates into a bottom-left collected strip and a non-blocking "FOUND! <name>" toast shows for ~2 s (no pointer capture, movement continues).
- **Globe HUD** (`GlobeHUD`) — timer/found chips, collapsible clue cards with hint panels, `Fly to <City>` buttons (selected = purple), `Pause`.
- **Results** (`ResultsScreen`) — medal badge, adjusted time, score, `Active · hints · travel` breakdown, best-on-device comparison (`+delta behind` / matched / First run; practice runs flagged as not saved), target photo strip, prominent yellow `Retry`, secondary `Next expedition`, `Menu`. No leaderboard.
- **Boot** (`BootScreen`, new) — wordmark, globe icon, one real gameplay tip, `model.statusMessage` or `Loading…`. No percentages, no artificial delay.
- **Travel / pause / error / map / orientation / touch** — restyled onto arcade panels/buttons. Map geometry and the landmark rule (`label !== null` only) are unchanged. Touch thumbstick colours only; axis callbacks unchanged.

## Known issues

- `UIModel.levels` exposes only `{ id, title }`, so menu tickets always show "First expedition"; showing a real per-trial best/medal on the menu needs A0 to add `bestMs`/`medal` per level to `UIModel.levels` (results screen already shows the real best from `ResultVM`).
- Difficulty/duration on tickets are static UI metadata (`trialMeta.ts`), not measured.
- Hint purchase is straight from the objective panel; the 700 ms disable is the double-press guard.
- Map is a plain rectangle projection; extreme aspect city bounds letterbox.
- Audio toggle is UI-only until a sound layer exists.
- `loop.spec.ts` e2e route-planner failure reported earlier is A7's helper, not re-verified in this pass.
